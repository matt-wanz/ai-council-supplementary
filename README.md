# Supplementary Material — AI Council: From Collaboration to Governance

This repository hosts the supplementary material for the ICSE 2027 SEIP submission:

**AI Council: From Collaboration to Governance — An Evolutionary Study of an AI Agent Governance Council for the Future**
(Zheng Wan, Independent Researcher; Tiara Wan, Liberal Arts (Boya) College, Chongqing University)

## Contents

- `paper_draft_v2.9_supplementary.pdf` — the supplementary package (v2.9.2, 2026-10-08):
  - **Appendix A**: Empirical data source index and reproducibility anchors
  - **Narrow-Domain F1 Detail**: false-positive analysis of the extraction layer
  - **Appendix C**: Lessons learned L7–L11 (preserved from body reductions)
  - **Table S1**: 19 documented AI-conclusion failure modes → governance module mapping
  - **Appendix E**: Control-plane integrity — incident ledger, production case, protocol evolution
- `paper_draft_v2.9_supplementary.tex` — LaTeX source of the supplementary package

## Versioning

The tag/release (e.g., `v2.9.2`) corresponds to the version cited in the submission and is
frozen at submission time. Any post-review updates will use a new version tag.
